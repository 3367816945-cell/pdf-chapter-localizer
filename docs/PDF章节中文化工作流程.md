# PDF 章节中文化工作流程

> 本文件是**可复用规范**，由第一章（`chp1_c++概览/`）与第二章（`chp2_函数与库/`）的实际施工过程提炼而成。
> 目标读本：`f:\CS106BX-Reader.pdf`（Eric S. Roberts, *Programming Abstractions in C++*, CS106B/X Reader, Autumn 2012, 1046 页）。
> 从第三章起，只需替换「章节号 + 页边界 + 节标题表」，其余照本文件执行，不必重新摸索。

---

## 0. 适用范围与输入输出

### 0.1 适用

把一本**库外大体积、带图表的学术 PDF** 的**单个章节**，转化为可在 Obsidian 中阅读、双链导航、带图学习的一组中文 Markdown 笔记。

不适用：扫描件（无文本层）、纯代码仓库文档、需要逐字直译的法律/合同文本。

### 0.2 输入

| 输入项 | 说明 | 获取方式 |
|---|---|---|
| PDF 路径 | 可位于库外，如 `f:\CS106BX-Reader.pdf` | 用户提供 |
| 章节号 | 如「第 2 章」 | 用户指定 |
| 页码换算关系 | 电子版页码与印刷页码的固定偏移 | 见第 1 节实测法 |
| 章节页边界 | 本章 PDF 起止页 | 见第 1 节 |
| 节标题表 | 每节的「原书页 / PDF 页 / 译名」 | 见第 1 节，来自目录页 + 逐页复核 |

### 0.3 输出

```
<库根>\
├── chpN_<中文短名>.md                 # MOC 章节索引（放库根）
└── chpN_<中文短名>/                   # 章节目录
    ├── N-1-<节名>.md … N-M-<节名>.md   # 各节正文
    ├── 小结.md
    ├── 复习题.md
    ├── 复习题-答案.md                   # 译者补充
    ├── 编程习题.md
    ├── 编程习题-参考答案.md              # 译者补充
    └── attachments/                    # 30–45 张 PNG
```

**命名约束**：目录名用**纯中文/ASCII**，不要放 `++` 等特殊符号。第一章目录名 `chp1_c++概览` 在 Obsidian 链接中会被转义成 `%2B%2B`，不美观，后续章节应避免（第二章已改名为 `chp2_函数与库`）。

### 0.4 已固化的全局决策（后续章节直接沿用）

| 决策项 | 固定方案 | 理由 |
|---|---|---|
| 翻译方式 | **忠实译述**（非逐字直译），术语首现处中英对照 | 兼顾可读性与准确性 |
| 文件组织 | **拆分为多文件 + 独立 MOC 索引** | 单文件过长不便检索与复习 |
| 图表处理 | **取原书图归档为 PNG**，用显式相对路径引用 | 见第 3 节；不重绘、不臆造 |
| 代码风格 | **标准库版**（`<iostream>` / `<cmath>` 等） | 原书第 1 章即用标准库；本机 `g++ 15.1.0` 可直接实跑验证 |
| 缩进 | 保留原书 **3 空格**缩进 | 与原书/截图逐行对齐，便于核对 |
| 答案详细度 | **要点式 + 实测输出** | 答案文件独立，标注「译者补充，非原书内容」 |

> 注：原书第 2.9 节起引入 Stanford 自定义库（`simpio.h` 等）。经核查 `F:\CS106B` 的 Stanford 库为 2021/2023 新版（**无 `genlib.h`**、`simpio.h` 只有小写 API 且无大写兼容宏、需 Qt 工程），**与原书 2012 写法不兼容**。因此正文照原书忠实译述并说明该库的用途，**所有可运行代码一律给标准库等价写法**，关键 API 处用 `> [!note] 译者注` 标明对照关系。

## 1. 章节边界定位

### 1.1 定位目录页

书前目录位于 PDF 第 3–8 页。导出后读章节表：

```powershell
& "F:\tex\miktex\bin\x64\pdftotext.exe" -f 3 -l 8 -layout "f:\CS106BX-Reader.pdf" "$env:TEMP\cs106b_toc.txt"
```

### 1.2 求页码换算关系（必做，不可沿用别书）

电子版通常有封面/前言等前置页，造成固定偏移。**求法**：取本章内任一页，读其**页眉**中的印刷页码，与 PDF 页码相减。

实测：PDF 第 66 页页眉为 `58   Functions and Libraries` → **偏移 = 8**，即

```
PDF 页码 = 原书页码 + 8
```

### 1.3 求本章上界（下一章首页）

用 `pdftotext` 抽验候选页的页首文本，找到 `Chapter N+1` 的起点作为上界。

实测：第 1 章 = PDF 9–62；第 2 章 = PDF 63–132；PDF 133 页首为 `Chapter 3 / Strings`。

### 1.4 产出节边界表（本章施工的唯一依据）

格式如下（第二章实例）：

| # | 节标题 | 原书页 | PDF 页 | 译名 |
|---|---|---|---|---|
| 2.1 | The idea of a function | 56 | 64–66 | 函数的概念 |
| 2.2 | Libraries | 59 | 67–68 | 库 |
| … | | | | |
| — | Summary | 112 | 120–121 | 本章小结 |
| — | Review questions | 114 | 122–123 | 复习题 |
| — | Exercises | 115 | 124 | 编程习题 |

**复核要求**：每节首页须抽验「节标题行 + 页眉页码」两项一致；允许 ±1 页的边界微调，**内容归属以不切断段落为原则**（若某段落在原书中跨节标题，归入其主体所在节，并在文末加译者注说明）。

## 2. 文本提取

### 2.1 逐页导出脚本（含页标记，供检索与引用）

```powershell
# <章号> 与 <起>..<止> 按第 1 节的边界表替换
$dir = "$env:TEMP\cs106b_chpN"; New-Item -ItemType Directory -Force $dir | Out-Null
foreach ($p in <起>..<止>) {
  $t = & "F:\tex\miktex\bin\x64\pdftotext.exe" -f $p -l $p -layout "f:\CS106BX-Reader.pdf" - 2>$null
  Add-Content -Encoding utf8 "$dir\pages.txt" "`n=== PAGE $p ===`n"
  Add-Content -Encoding utf8 "$dir\pages.txt" $t
}
```

**验收**：`pages.txt` 内 `=== PAGE N ===` 标记数 = 页数（如 70 页应得 70 个标记）。

### 2.2 `pdftotext` 文本失真清单（8 条，必须人工还原，不可照抄）

| # | 失真现象 | 实例 | 还原规则 |
|---|---|---|---|
| 1 | `!` 出现在**数学语境** | `!/4`、`! square inches` | 实为 **π** |
| 2 | `!` 出现在**数值语境** | `!1 as the sentinel` | 实为**负号 −** |
| 3 | **上标被压平** | `up to 28`、`215–1`、`231–1` | 实为 2⁸、2¹⁵−1、2³¹−1，须结合上下文还原 |
| 4 | **数学符号丢失** | `h " w`、只剩占位符的根号/求和号 | `"` 实为 `×` 或 `·`；公式缺失处按截图补回或用 LaTeX 重写 |
| 5 | **图形与表格结构丢失** | ASCII 表、真值表、优先级表错行 | **一律改用截图**，不试图从文本重建 |
| 6 | **行尾 `-`** | `abstrac-` `tion` | 折行符，须与下一行合并 |
| 7 | **页眉页脚混入正文流** | `58   Functions and Libraries`、`2.1 The idea of a function   57` | 剔除，不得写入译文 |
| 8 | **引号被替换为弯引号** | `' ' " "` | 代码中的字符串常量必须还原为**直引号** `"` |

**附注**：`-layout` 能保住缩进，但**代码注释可能被截断**，须与截图核对。

### 2.3 章节体量评估

统计 `pages.txt` 字符数，用于第 6 节的分组均衡：

| 章 | 页数 | 字符数 | 节数 | 复习题 | 编程题 |
|---|---|---|---|---|---|
| 第 1 章 | 54 | ≈99,000 | 7 | 26 | 12 |
| 第 2 章 | 70 | ≈145,600 | 9 | 29 | 18 |

## 3. 图表归档（双轨）

### 3.1 轨道选择判据

| 轨道 | 触发条件 | 命令 |
|---|---|---|
| **A：无损导出内嵌位图** | `pdfimages -list` 中该页存在大尺寸 image 对象 | `pdfimages -png -f N -l N <pdf> <out>` |
| **B：整页渲染 + 裁切** | 图框为矢量绘制，或为表格/真值表 | `pdftoppm -png -r 150 -f N -l N <pdf> <out>` |

> 两章实测对比：第 1 章图框**以矢量为主**，只能走轨道 B；第 2 章含 **60+ 个内嵌位图对象**，走轨道 A 可显著提升清晰度。**每章都要先跑 `-list` 实测再决定**，不可臆断。

### 3.2 命令

```powershell
# 位图清单（必做第一步）
& "F:\tex\miktex\bin\x64\pdfimages.exe" -list -f <起> -l <止> "f:\CS106BX-Reader.pdf"

# 轨道 A：无损导出某页位图（输出文件名形如 out-000.png、out-001.png）
& "F:\tex\miktex\bin\x64\pdfimages.exe" -png -f 75 -l 75 "f:\CS106BX-Reader.pdf" "$env:TEMP\cs106b_chpN\bit"

# 轨道 B：整页渲染（输出形如 shot-075.png，编号按总页数补零）
& "F:\tex\miktex\bin\x64\pdftoppm.exe" -png -r 150 -f 75 -l 75 "f:\CS106BX-Reader.pdf" "$env:TEMP\cs106b_chpN\shot"
```

分辨率：默认 `-r 150`；若单页 > 2 MB 或文字发虚，重渲染 `-r 200`。

### 3.3 噪声排除清单（不归档）

| 特征 | 说明 |
|---|---|
| 约 `133×67`、数百字节 | 页眉装饰小图标 |
| 约 `858×929`、≈41.5 K、多页 MD5 相同 | 全书通用插图/图标（与第一章判定为噪声的 `img-022` 同源） |
| 章首/章末装饰性图案 | 与知识点无关 |

### 3.4 补档规则

逐页扫过本章页范围，凡正文出现 `Figure N-M` / `Table N-M` 引用而归档清单无对应图者，**回查该页渲染图补档**。

### 3.5 命名规则

格式：`{类型}-{编号}-{中文短名}-p{PDF页}.png`

| 前缀 | 用于 | 示例 |
|---|---|---|
| `fig-N-M` | 有编号的 Figure | `fig-2-3-函数调用栈帧-p75.png` |
| `table-N-M` | 有编号的 Table | `table-2-1-...-pNN.png` |
| `ex-N` | 编程习题的样例输出/图形 | `ex-16-彩虹-p131.png` |
| `code-x` | 无编号的代码框 | `code-x-循环头行与循环体-p20.png` |
| `fig-x` | 无编号的插图 | `fig-x-幂次样例运行-p16.png` |

### 3.6 输出归档清单

建成「文件名 ↔ PDF 页 ↔ 原书页 ↔ 所属节」四列表，作为第 6 节子代理嵌入引用的**唯一依据**（子代理不得自行推测图片位置）。

## 4. 目标产物约定

### 4.1 frontmatter 模板（六字段，逐字段照抄）

```yaml
---
title: 2.1 函数的概念
chapter: 2
section: "2.1"
source: "Programming Abstractions in C++ (CS106B/X Reader, Autumn 2012)"
source_pages: "原书 56–58 页 / PDF 64–66 页"
tags:
  - CS106B
  - C++
  - 编程抽象
  - 第2章
---
```

- `section`：章末文件分别写 `"Summary"` / `"Review questions"` / `"Exercises"`；答案文件写 `"Review questions — 译者补充答案"` / `"Exercises — 译者参考实现"`。
- `tags` 末项固定为 `第N章`。
- MOC 用 `type: MOC`、`title: 第N章 <中文名>`。

### 4.2 排版约定八条

1. **标题**：文件首行 `# N.M <中文节名>`，与 frontmatter `title` 一致。节内小标题用 `##`，忠实对应原书的灰底小标题，不自行重排层级。
2. **术语**：首现处写 **`**中文（english）**`** 加粗对照，此后一般只用中文。英文术语、代码标识符、库名、函数名**一律保留英文原样**。
3. **图片**：`![图 2-3 描述（原书 62 页，PDF 70 页）](attachments/fig-2-3-中文短名-p70.png)` —— 说明文字中**必须含原书页 + PDF 页**。附件一律用**显式相对路径**（`.obsidian/app.json` 未配置 `attachmentFolderPath`，默认落库根，故不可用裸文件名）。
4. **代码块**：```` ```cpp ```` + **原书 3 空格缩进** + 保留原书注释。代码前用一句话引出，例如：「下面是图 2-3 中代码清单的完整文本，可复制运行（保留原书缩进；其中以 `// 译注：` 开头的注释为译者新增，其余为原书所有）：」
5. **公式**：用 LaTeX（`$$F = \frac{9}{5}\,C + 32$$`），不要用文本层的残缺符号。
6. **wikilink**：同章互链 `[[2-4-函数调用的机制]]`，带别名 `[[2-2-库|上一节]]`。**只允许链接本轮将存在的文件**，禁止指向尚未创建的章节。
7. **运行示例**：原书的样例输出用 `> [!example]` 原样照录，不改写、不美化。
8. **译者补充**：一切非原书内容必须落在 callout 中，与正文明确区分。

### 4.3 callout 类型表

| 类型 | 用途 |
|---|---|
| `> [!quote] 章首题词` | 名人引语，英文原文 + 中译并列 |
| `> [!note] 译者注` | 译者补充背景、版本差异说明、术语辨析 |
| `> [!tip] 学习提示` | 原书方法论、学习路径建议 |
| `> [!example] 样例运行` | 程序运行输出 |
| `> [!warning] 阅读时请注意` / `易错点` | 版本差异、易错点、已知偏差 |

**格式**：`> [!xxx] 标题`（`]` 与标题之间**必须有空格**，Obsidian 才会渲染成 callout 头部）。

## 5. 术语表维护

1. **每章建独立术语表**，在 MOC 的 `## 术语表` 小节以 `| English | 中文 | 备注 |` 三列表呈现。
2. **跨章一致**：第 1 章已定的译法（表达式 / 语句 / 函数 / 变量 / 数据类型 / 标识符 / 运算符 / 优先级 / 结合性 / 强制类型转换 / 布尔 / 真值表 / 哨兵值）在后续章节**沿用不改**。
3. **首现即登记**：子代理译述时若引入新术语，须一并写入术语表，避免各节译法不一致。
4. **一义一词**：同一英文词全章只用同一个中文译名；不同英文词不用同一中文词。
5. **保留英文的三类**：语言关键字（`while`/`for`/`switch`）、API 名（`GetInteger`）、库名（`simpio.h`）。

> 第二章实例：function 函数、library 库、client 客户（调用方）、interface 接口、implementation 实现、prototype 原型、argument 实参、parameter 形参、signature 签名、overloading 重载、predicate function 谓词函数、stack frame 栈帧、call by value 值调用、call by reference 引用调用、scope 作用域、pseudorandom number 伪随机数、seed 种子、boilerplate 样板代码、header file 头文件。

## 6. 并行子代理拆分

### 6.1 拆分原则

- 按**节体量均衡**分组，单组 **≤ 4 节且 ≤ 15 页**；超长节（如第 2 章 2.8 节独占 17 页）**单独成组**。
- 章末三件套（Summary / Review / Exercises）合成一组，且必须与做答案的步骤对齐（题号、顺序、截图引用一致）。
- 组数参考：第 1 章 5 组，第 2 章 6 组（因 2.8 节过大）。
- **并行派发**：在**同一条消息内**同时发起多个子代理调用。

### 6.2 子任务指令 7 要素（缺一不可）

1. **取文本的确切命令**（页范围 + 输出路径），强调不得凭记忆写作：
   ```powershell
   & "F:\tex\miktex\bin\x64\pdftotext.exe" -f <起> -l <止> -layout "f:\CS106BX-Reader.pdf" -
   ```
2. **目标文件的绝对路径** + 硬约束：一个节一个文件、不合并、不改名；**只准创建这些文件**（答案文件属另一步骤）。
3. **第 4 节的完整约定**：frontmatter 模板、排版八条、callout 类型表；连同第 5 节的术语表一并给出。
4. **第 2.2 节的八条失真清单**，并要求：失真处须读对应页截图核对，**不得猜测**；仍不确定则写 `> [!warning] 原文此处为公式/图形，请对照截图 …` 并给出截图链接。
5. **该节涉及的截图文件名清单 + 嵌入位置**（由第 3.6 节归档清单提供）；并授权「若发现清单外的图表，一并归档并按第 3.5 节命名」。
6. **禁止编造**：不得生成原文没有的段落、代码、数据、页码、示例输出。
7. **wikilink 范围**：允许本章内互链，**禁止指向不存在的笔记**（尤其不得链接到下一章文件）。

### 6.3 越界防护（必须写进指令）

- 子代理**只准创建分配到的 md 文件**，不准创建 `复习题-答案.md` / `编程习题-参考答案.md`。
- 子代理**不准改动已交付章节**（如 `chp1_c++概览/`）的任何文件。
- 代码若能从文本完整还原 → 写 ```` ```cpp ```` 代码块；**若代码位于图框内且文本提取失真/缺失 → 只嵌图片，不凭猜写代码**。

## 7. 章末三件套 + 答案

### 7.1 小结（`小结.md`）

格式：`本章要点包括：` + bullet 列表；关键处嵌 ```` ```cpp ```` 片段；末尾用 `参见 [[N-x-节名]]` 回链。

### 7.2 复习题（`复习题.md`）

- 逐题 `### N.` + 题干译文，**不含答案**。
- 顶部 `> [!note] 译者注` 写明：本页只给题干（与原书体例一致），答案见 `[[复习题-答案]]`（译者补充，非原书内容），并列可参见的节文件。

### 7.3 编程习题（`编程习题.md`）

- 逐题 `### N.` + 题干译文；原书的样例运行、配图照录。
- 顶部 `> [!tip] 参考答案` callout 指向 `[[编程习题-参考答案]]`。

### 7.4 答案文件两条硬约定

1. **顶部声明**：`> [!warning] 译者补充，非原书内容`，说明原书不提供答案、代码用标准库编写、已在 `g++ 15.1.0` 下实跑。
2. **每题溯源**：概念题后加 `> 出处：[[N-x-节名]]`。

### 7.5 答案格式

- **复习题-答案.md**：`### N.` → `**答案**：…` → `> 出处：[[…]]`。判断题须给判定 + 理由；问原型的题须给准确签名；需演算的题须给逐步推导。
- **编程习题-参考答案.md**：`### N.` → `**思路**` → `**要点提醒**` → ```` ```cpp ```` → `**实测运行**（g++ 15.1.0 -std=c++17）` → ```` ```text ````。

### 7.6 实测口径

- **凡涉及代码求值的题，必须建临时 `.cpp` 真跑后粘贴真实输出**，禁止凭记忆粘贴。
- 交互式程序用 **PowerShell 管道**喂 stdin（见第 9 节），样例值取自题面已有样例，不自造输入。
- 输出块中提示符/文字须与题面样例一致。

### 7.7 无法用标准库实现的题（如图形库题）

- 正文照原书转录题意 + 嵌入原书配图；
- 代码块给**标准库可运行的等价替代实现**，并加 `> [!note] 译者注` 说明差异；
- `**实测运行**` 块如实粘贴**替代实现**的输出，**绝不伪造图形库的运行结果**；
- 若超出合理篇幅，降级为「思路 + 要点提醒 + 译者注」，并在文件顶部 callout 列明降级题目编号。

### 7.8 双向接线

| 文件 | 接线内容 |
|---|---|
| `复习题.md` | 译者注中写入指向 `[[复习题-答案]]` 的说明 |
| `编程习题.md` | 插入 `> [!tip] 参考答案` callout 指向 `[[编程习题-参考答案]]` |
| MOC | 目录表含两份答案文件入口；已知偏差写明「答案属译者补充」；学习进度追加对应条目 |

## 8. MOC 结构与接线

MOC 放**库根**，文件名 `chpN_<中文短名>.md`，含以下小节：

| 序号 | 小节 | 内容要点 |
|---|---|---|
| 1 | frontmatter | `title: 第N章 <中文名>`、`type: MOC`、`chapter: N`、`tags` 含 `第N章` 与 `MOC` |
| 2 | `> [!quote] 章首题词` | 英文原文 + 中译并列 |
| 3 | `## 章首引言` | 转述原书本章开头数段的引入性文字 |
| 4 | `## 本章目录` | 表格 `\| # \| 笔记 \| 覆盖范围 \| 读完后你将掌握…… \|`，**每节一行 + 章末三件套 + 两份答案文件** |
| 5 | `> [!tip] 学习提示` | 阅读顺序与学习路径建议 |
| 6 | `## 术语表` | 第 5 节的表 |
| 7 | `## 对照表` | `\| 节 \| 标题 \| 原书页 \| PDF 页 \| 本笔记文件 \|`，**首句写明页码换算关系**；表后注明附件目录与张数 |
| 8 | `## 已知偏差` | `> [!warning] 阅读时请注意` + 分组编号项 |
| 9 | `## 学习进度` | `- [ ]` 复选框列表，条目数 = 笔记文件数（含两份答案文件） |

**三处接线**（易漏，须核对）：① 本章目录表含答案文件入口；② 已知偏差更新（至少含「答案属译者补充」「与标准库的差异」「无法用标准库实现的题的替代方案」「缩进为原书 3 空格」）；③ 学习进度追加答案相关条目。

## 9. 环境注意事项

### 9.1 环境陷阱（实测，必须遵守）

1. **`cmd /c` 被安全策略完全禁用** → 报错 `The use of 'cmd /c' (or 'cmd.exe /c') is blocked on Windows for safety.`。喂 stdin **一律用 PowerShell 管道**：
   ```powershell
   "100" | .\q01.exe
   @("17","42","21","19","35","0") | .\q05.exe
   ```
2. **PowerShell 不支持 `<` 输入重定向符号**（`.\q01.exe < input.txt` 会失败）。
3. `$env:TEMP` = `C:\Windows\TEMP`（不是用户目录下的 Temp）。
4. **MCP 工具取舍**：`mcp_pdf-reader-mcp` 拒绝绝对路径与 `..` 路径穿越 → 源文件在库外时**不可用**，弃用；`mcp_nanopdf` 可用于单页预览，但不适合批量提取 → 一律优先用 MiKTeX 的 poppler 三件套。

### 9.2 工具链

| 工具 | 路径 | 用途 |
|---|---|---|
| `pdftotext.exe` | `F:\tex\miktex\bin\x64\` | 文本提取（`-f/-l/-layout`，`-` 输出 stdout） |
| `pdftoppm.exe` | 同上 | 页面渲染截图（`-png -r 150 -f N -l N`） |
| `pdfimages.exe` | 同上 | 内嵌位图导出（`-list` / `-png`） |
| `pdftocairo.exe` | 同上 | 备用渲染 |
| `g++.exe` | `E:\mingw64\bin\` | 15.1.0，编译口径 `-std=c++17 -O2` |

`clang++` / `cl` 在本机不可用。

### 9.3 收尾清理

每章施工完成后删除临时目录，并用 `Test-Path` 确认：

```powershell
Remove-Item -Recurse -Force "$env:TEMP\cs106b_chpN" -ErrorAction SilentlyContinue
Remove-Item -Recurse -Force "$env:TEMP\cs106b_chpN_ans" -ErrorAction SilentlyContinue
Test-Path "$env:TEMP\cs106b_chpN"   # 期望 False
```
